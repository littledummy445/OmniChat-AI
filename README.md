# OmniChat AI

A powerful, feature-rich ChatGPT clone designed to deliver advanced multimodal artificial intelligence capabilities directly in your browser. Built with modern web technologies and persistent storage, OmniChat AI bridges conversational intelligence, visual creation, and media production into a single, seamless interface.

## Features

- **Advanced Text Conversations:** Powered by Google's latest Gemini models for context-aware, highly intelligent, and rapid dialogue.
- **AI Image Generation & Editing:** Create stunning, high-resolution visual assets from text prompts and edit existing imagery on the fly.
- **AI Video Creation:** Harness the power of advanced video models (such as Google's Veo) to generate cinematic video sequences directly from text descriptions.
- **Persistent Storage:** Automatically saves chat histories and session states locally so you never lose your important prompts or generated media.
- **Sleek UI:** Built with a modern "Liquid Glass" design aesthetic, smooth animations, and responsive layouts.

## Tech Stack

- **Frontend:** HTML5, CSS3 (Custom Glassmorphism & Animations), JavaScript (ES6+)
- **AI Integration:** Google Gemini & Veo models
- **Storage:** LocalStorage / IndexedDB for session persistence
